Если в аргументах путь к документу, то прочитай его и используй как контекст.

Полные проверки — один раз: команду берёт из AGENTS.md / CLAUDE.md проекта, без неё — собирает из CI и скриптов (workflows, package.json scripts, Makefile, pre-commit). После успешного прогона без правок не повторять, сценарии задачи не перепроверять. Падения — по правилам `grilling`.

Коммить только изменения задачи: файлы добавляй по имени; неотслеживаемые файлы вне задачи и секреты не добавляй — спроси. Документы — в коммите с кодом, который они описывают; в fix — корневая причина в теле. Состав проверь `git log --stat` отдельной командой до пуша.

`git push -u origin HEAD`, если нет открытых вопросов и текущая ветка не основная (ветка по умолчанию remote, main, master); на основной не пушь — остановись и спроси.
