# sol-loop

Цикл ревью: GPT Sol проверяет изменение, ты исправляешь — пока Sol не одобрит
или не кончатся раунды. Правь минимально и спорь с неверными замечаниями.

## Что ревьюим

Всё, чем рабочее дерево отличается от базы: коммиты, незакоммиченные правки и
неотслеживаемые файлы.

- База: `git merge-base HEAD origin/<основная-ветка>`. Нет remote — `HEAD`.
- Изменение: `git diff <base>` плюс неотслеживаемые файлы из `git status --short`.

Перед первым раундом запусти тесты и линтер, которые покрывают изменение, и
запиши результат.

## Раунд

Sol запускается через Codex CLI из корня репозитория, бриф передаётся через stdin.
Модель берётся из `~/.codex/config.toml`. Если `codex` не запускается, сообщи
пользователю; другую модель не подставляй.

Первый раунд — новая сессия только на чтение:

```bash
codex exec -s read-only --json -o /tmp/sol-review.txt - <<'EOF' > /tmp/sol-review.jsonl
<бриф>
EOF
```

ID сессии — `thread_id` из первой строки `/tmp/sol-review.jsonl`, ответ Sol — в
`/tmp/sol-review.txt`. Ставь таймаут Bash 600000 мс: раунд идёт минуты.

Пока Sol работает, файлы не правь. Ненулевой код выхода или пустой ответ — не
одобрение.

Бриф (Sol не видит переписку):

```
Только ревью: ничего не редактируй и не коммить.
Репозиторий: <путь> База: <sha> Цель: <1–2 предложения> Проверки: <результаты>
Изменение: git diff <base> и неотслеживаемые файлы из git status --short.
Ищи баги, сломанные вызовы и расхождения с целью. Стиль — только если скрывает баг.
блокер = основной сценарий работает неверно. важно = реальный баг в рамках цели. мелочь = остальное.
Ответ:
ВЕРДИКТ: ОДОБРЕНО или НУЖНЫ ПРАВКИ
S1 [блокер|важно|мелочь] <файл>:<строка> <проблема>. Исправление: <предложение>
```

## Разбор замечаний

Проверь каждое замечание сам.

- Согласен — минимальное исправление: удалить или сузить лучше, чем добавить код.
- Не согласен — ответь с доказательством (файл:строка, тест, вывод команды).
- Мелочь или вне рамок — откажи одной строкой.

Перезапусти проверки.

## Следующий раунд

Не больше 3 раундов, до 5 — если попросил пользователь. Следующий раунд нужен,
только если остался открытый «блокер» или «важно» или изменилось поведение кода.

Продолжи ту же сессию Codex — она помнит прошлые раунды:

```bash
codex exec resume -c sandbox_mode='"read-only"' -o /tmp/sol-review.txt <thread_id> - <<'EOF'
<сообщение>
EOF
```

В сообщении: что исправлено, с чем не согласен и почему. Попроси смотреть
только открытые замечания и изменённый код и пометить каждый старый id как
«решено» или «открыто: <причина>».

## Итог

Готово, когда Sol дал «ОДОБРЕНО» и открытых «блокер» и «важно» нет. Если спор не
решился за два ответа или кончились раунды — покажи обе позиции, решает
пользователь.

Коммить и пушь, только если пользователь просил. Отчёт: число раундов,
исправленные и отклонённые замечания с причинами.
