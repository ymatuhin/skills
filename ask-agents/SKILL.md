Получи ответ на задачу из аргументов от Codex и Claude и сведи их в итог. Ты ведущий: запускаешь агентов, разбираешь их пункты и споры по коду, но задачу сам не выполняешь. Ничего не меняй, кроме итога `ask-agents.md` в каталоге задачи: правки по итогу вносит [implement](../implement/SKILL.md). До работы прочитай [grilling](../grilling/SKILL.md).

## Промпт

Агенты не видят разговор и получают один промпт:

- аргументы дословно. Команда скила (`/review-changes`, `$review-changes`) — первым словом: Claude вызывает скил только из начала промпта. Сам этот скил не выполняй — это задача агентов;
- если аргументы опираются на разговор («это», «план выше») — после них абзац «Контекст:» с решениями, ограничениями и абсолютными путями. Без скила промпт должен говорить, что считать результатом.

Режим консультации и формат отчёта `run.sh` добавляет сам: [ROUND-1.md](ROUND-1.md).

## Раунды

Каталог — тот, к которому относится задача (корень репозитория, `~/.claude/skills` и т. п.). Прогон бывает дольше 10 минут; запускай каждый раунд вне песочницы shell: агентам нужны сеть и запись в `~/.codex` и `~/.claude`.

- В Codex используй `exec_command` с `sandbox_permissions: "require_escalated"` и `yield_time_ms: 1000`. Если вернулся `session_id`, жди завершения через `write_stdin` с этим ID, пустым `chars` и `yield_time_ms: 30000`; повторяй ожидание до получения `exit_code` и сохраняй весь вывод. Если команда завершилась сразу, переходи к её результату.
- В Claude Code используй `Bash` с `run_in_background: true` и `dangerouslyDisableSandbox: true`; дождись завершения фоновой задачи и прочитай её вывод.

Пока агенты работают, задачу сам не решай. Следующий раунд запускай только после завершения текущего.

1. **Отчёты.** Оба агента выполняют промпт независимо:

   ```bash
   ~/.claude/skills/ask-agents/run.sh -C <каталог> <<'PROMPT'
   <промпт>
   PROMPT
   ```

   Первая строка вывода — каталог прогона, дальше по строке на агента: `ok <путь к answer.md>` или `failed — <причина>`. ID у Claude — `CL-1`, `CL-Q1`, у Codex — `CX-1`, `CX-Q1`.
2. **Перекрёстная проверка.** Каждый агент проверяет отчёт другого ([CROSS.md](CROSS.md)): `run.sh -C <каталог> --cross <каталог прогона>`. Пропусти, если ответил один агент или ни у кого нет пунктов.
3. **Ответ на опровержения.** Агенту, чьи пункты другой опроверг или кому добавил «Новые находки», — `run.sh -C <каталог> --cross <каталог прогона> <codex | claude>`; обоим — без имени. Нечего отвечать — пропусти. Это последний раунд: `run.sh` четвёртый не запустит.

Ответы агентов читай целиком.

## Итог

Разложи пункты по последнему вердикту:

- подтверждён другим агентом или дубликат — «Принято»;
- опровергнут, автор согласен — «Отклонено»;
- автор настаивает, новая находка опровергнута в раунде 3 или раунд не состоялся — проверь сам по коду: решается однозначно — реши с доказательством, источник «ведущий»; иначе — «Спорное» с позициями обоих;
- ответил один агент — каждый его пункт проверь сам по коду, пометка «без перекрёстной проверки»;
- вопрос, подтверждённый другим, — «Вопросы пользователю»; опровергнутый ответом из кода — «Отклонено» с ответом.

У пункта «Принято» с правкой статус «ожидает», без правки — «вывод». Запиши итог в каталог задачи: если в аргументах путь к документу задачи — в его каталог, иначе создай `/tmp/handoffs/<yyyy-mm-dd>-<slug>/`. Файл — `ask-agents.md`; уже есть — `ask-agents-2.md` и дальше по номеру. Файлы раундов остаются в каталоге прогона. Пустые разделы убирай:

```md
# Итог: <задача одной строкой>

Промпт: <каталог прогона>/claude/round-1/prompt.md. Каталог: <каталог>. Раундов: <1–3>[; <сбой агента — причина>].

## Принято
- **<ID[, ID]>** [Claude | Codex | оба | ведущий][; без перекрёстной проверки] <где> — <проблема> → <исправление>. Статус: ожидает | вывод

## Спорное
- **<ID>** <где> — Claude: <позиция, доказательство>; Codex: <позиция, доказательство>. Статус: вопрос В<N>

## Вопросы пользователю
- **<ID>** [Claude | Codex | оба] <вопрос>. Статус: вопрос В<N>

## Отклонено
- **<ID>** <суть> — отклонил <Claude | Codex | ведущий>: <причина>
```

## Разговор

Ответ — по правилам `grilling`: «Спорное» и «Вопросы пользователю» — вопросами В<N>, пункты, которые решил ты, — в «Решено по умолчанию». Затем «Принято» — по строке на пункт с источником, «Отклонено» — строкой с причиной, путь к итогу. Ответы агентов целиком не показывай, по просьбе пользователя — дословно.

После ответов пользователя обнови итог: пункт, который решено править, — в «Принято» со статусом «ожидает», решено не править — в «Отклонено» с причиной. Итог — единственный актуальный список по задаче.

Команды следующих шагов показаны для Codex (`$имя`). В Claude Code замени префикс каждого вызова на `/`, включая вложенный вызов: `$ask-agents $review-changes` → `/ask-agents /review-changes`.

Когда открытых вопросов нет и есть пункты «ожидает» — предложи отдельным fenced-блоком без языка:

```
$implement <путь к итогу>
```

## Сбои

Сбой агента — одной строкой с причиной; продолжай с ответившим и отметь сбой в итоге. Упали оба — сообщи причины и остановись.

Если автоматическая проверка отклонила запуск из-за передачи незакоммиченных файлов внешнему сервису — запроси у пользователя явное разрешение передать эти изменения агентам для read-only консультации. После согласия повтори запуск с повышенными правами; без согласия не повторяй.
