Выполни задачу из аргументов вместе с внешним агентом по [протоколу](PROTOCOL.md) — прочитай его до работы: независимые отчёты, перекрёстная проверка, итог в `final.md`. Внешний агент — другой, чем ты: из Claude — Codex, из Codex — Claude; хост определяет скрипт. Он работает read-only, в своей модели по умолчанию с high effort; правки вносишь ты.

Агент не видит разговор. Составь промпт, по которому задачу можно выполнить без вопросов:

- задача и что считать результатом;
- контекст из разговора, который влияет на ответ: решения, ограничения, пути;
- режим: файлы не правь, вопросов не задавай, внешних агентов не запускай;
- формат: отчёт по разделу «Отчёт» в `~/.claude/skills/ask-agents/PROTOCOL.md`.

Рабочий каталог — тот, к которому относится задача (корень репозитория, `~/.claude/skills` и т. п.). Раунд 1 — в фоне и вне песочницы, как в протоколе:

```bash
~/.claude/skills/ask-agents/run.sh -C <каталог> <<'PROMPT'
<промпт>
PROMPT
```

Дальше — по протоколу: свой отчёт, сверка, перекрёстная проверка, `final.md`, сбои.

Правки и решения — по правилам [grilling](../grilling/SKILL.md): обоснованное и механическое исправь сам и покажи в «Решено по умолчанию»; изменение поведения, решений пользователя и спорное — вопросом.

## Из другого скила

Скил запускает агента своим экземпляром: `<аргументы>` — аргументы для него, обычно с флагом режима внешнего агента. Codex получает `$<скил> <аргументы>`, Claude — `/<скил> <аргументы>`:

```bash
~/.claude/skills/ask-agents/run.sh -C <каталог> --skill <скил> '<аргументы>'
```

Дальше — по [протоколу](PROTOCOL.md). Вызывающий скил задаёт, что проверять, ответ внешнего агента в своём режиме — отчёт по протоколу — и свои правила `grilling`.
