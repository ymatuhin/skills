# Протокол совместной работы агентов

Хост — агент в разговоре с пользователем. Внешний агент — другой: из Claude — Codex, из Codex — Claude; его запускает [run.sh](run.sh). Внешний агент работает read-only и не видит разговор; его ответ скрипт сохраняет в файл. Хост проверяет работу внешнего агента, внешний — работу хоста; итог собирает хост.

## Файлы

Все файлы — в каталоге прогона, который `run.sh` печатает первой строкой:

| Файл | Кто пишет | Что |
| --- | --- | --- |
| `host-1.md` | хост | отчёт хоста, раунд 1 |
| `<агент>/round-1/answer.md` | скрипт | отчёт внешнего агента, раунд 1 |
| `host-2.md` | хост | вердикты хоста по пунктам внешнего агента |
| `<агент>/round-2/answer.md` | скрипт | вердикты внешнего агента по пунктам хоста и ответы на опровержения |
| `final.md` | хост | итог: всё актуальное по задаче |

Рядом с `answer.md` лежат `prompt.md`, `err.txt` и журнал агента (`events.jsonl` у Codex, `result.json` у Claude) — для разбора сбоев.

## Отчёт

Формат `host-1.md` и ответа внешнего агента в раунде 1. ID — префикс агента (`CL` — Claude, `CX` — Codex) и сквозной номер; вопросы — с `Q`: `CL-1`, `CX-Q1`. Хост не определён и запущены оба агента — у хоста префикс `H`.

```md
# Отчёт <Claude | Codex>

## Находки

### <ID> <суть в одну строку>
- Где: <файл:строка или пункт документа>
- Проблема: <что не так и почему — доказательство из кода>
- Исправление: <предлагаемый текст или правка>
- Уверенность: уверен | не уверен — <чего не хватает для проверки>

## Вопросы

### <ID-Q> <вопрос пользователю>
<почему кодом и документами не решается; варианты, рекомендация первой>
```

Находка без привязки к файлу:строке или пункту документа — не находка. Нет находок или вопросов — «Находок нет» или «Вопросов нет» в разделе.

## Вердикты

Формат `host-2.md` и ответа внешнего агента в раунде 2:

```md
# Вердикты <Claude | Codex>

| Пункт | Вердикт | Доказательство |
| --- | --- | --- |
| CX-1 | подтверждаю | <файл:строка — почему> |
| CX-2 | опровергаю | <файл:строка — почему> |
| CX-3 | дубликат CL-2 | |
| CL-4 | настаиваю | <новое доказательство> |
| CL-5 | согласен | |
```

`подтверждаю`, `опровергаю`, `дубликат <ID>` — про чужие пункты, `согласен` и `настаиваю` — про свои опровергнутые. Вопрос другого агента — `подтверждаю`, если его не решить кодом, или `опровергаю` с ответом из кода.

Новые находки раунда 2 — после таблицы разделом «Новые находки» по формату «Отчёт». Хост проверяет их по коду; в `final.md` они идут без перекрёстной проверки.

## Ход работы

1. **Раунд 1, запуск.** Запусти `run.sh` в фоне до своей работы (`run_in_background`; прогон бывает дольше 10 минут) и вне песочницы shell: агенту нужны сеть и запись в `~/.codex` или `~/.claude` (в Codex — эскалация, в Claude Code — `dangerouslyDisableSandbox`). Команду задаёт вызывающий скил или [ask-agents](SKILL.md).
2. **Раунд 1, свой отчёт.** Выполни задачу сам и запиши `host-1.md` до того, как читать ответ внешнего агента: так отчёты независимы. Правок пока не вноси.
3. **Сверка.** Каждый пункт внешнего агента проверь по коду и документам и запиши `host-2.md`.
4. **Раунд 2, перекрёстная проверка.** Если в `host-1.md` есть пункты, которых нет у внешнего агента, или в `host-2.md` есть «опровергаю» — отправь в ту же сессию:

   ```bash
   ~/.claude/skills/ask-agents/run.sh -C <каталог> --resume <каталог прогона> <<'PROMPT'
   Другой агент выполнил ту же задачу независимо. Его отчёт — <каталог прогона>/host-1.md, его вердикты по твоим пунктам — <каталог прогона>/host-2.md. Прочитай оба и проверь по коду: каждый его пункт — подтверждаю, опровергаю или дубликат твоего; каждый твой пункт, который он опроверг, — согласен или настаиваю с новым доказательством. Новую находку добавь, только если нашёл её при этой проверке, с ID, продолжающим твою нумерацию, — после таблицы разделом «Новые находки». Файлы не правь, вопросов не задавай, внешних агентов не запускай. Ответ — таблица вердиктов по ~/.claude/skills/ask-agents/PROTOCOL.md, раздел «Вердикты».
   PROMPT
   ```

   Иначе раунд 2 пропусти. Третьего раунда нет. Хост не определён и запущены оба агента — продолжай каждого отдельно: `--resume <каталог прогона> <агент>`.
5. **Итог.** Разложи пункты и запиши `final.md`:
   - подтверждён другой стороной или совпал у обоих — «Принято»;
   - опровергнут, и автор согласен — «Отклонено»;
   - автор настаивает или стороны разошлись — перепроверь по коду: однозначно решается — по коду, с доказательством; иначе — «Спорное», вопрос пользователю с позициями обоих. Свой пункт, опровергнутый внешним агентом, сам не принимай;
   - раунд 2 не проводился — пункты внешнего агента по вердиктам `host-2.md`, свои — «Принято» с пометкой «без перекрёстной проверки» в источнике.
6. **Разговор.** «Принято» и «Спорное» обработай по правилам [grilling](../grilling/SKILL.md) вызывающего скила: решаемое самим исправь и покажи в «Решено по умолчанию», остальное — вопросами. У пункта — источник: «Claude», «Codex» или «оба»; отклонённые — одной строкой с причиной. Ответы агентов целиком не показывай, по просьбе пользователя — дословно; дай путь к `final.md`.
7. **Актуальность.** После правок и ответов пользователя обнови статусы в `final.md`: он — единственный актуальный список по задаче. Решённый пункт «Спорного» или «Вопросов», который требует правки, перенеси в «Принято» со статусом «ожидает» или «исправлено».

`final.md`:

```md
# Итог: <задача>

Прогон: <каталог прогона>. Агенты: <Claude, Codex>. Раунд 2: проведён | пропущен — <причина> | сбой — <причина>.

## Принято
- **<ID[, ID]>** [Claude | Codex | оба[; без перекрёстной проверки]] <где> — <проблема> → <исправление>. Статус: ожидает | исправлено | вопрос В<N>

## Спорное
- **<ID>** <где> — Claude: <позиция, доказательство>; Codex: <позиция, доказательство>. Статус: вопрос В<N> | решено: <решение>

## Вопросы пользователю
- **<ID>** [Claude | Codex | оба] <вопрос>. Статус: открыт | решено: <ответ>

## Отклонено
- **<ID>** <суть> — отклонил <Claude | Codex>: <причина>
```

## Сбои

`run.sh` печатает по строке на агента: `<агент>: ok <путь к answer.md>` или `<агент>: failed — <причина>`. Сбой раунда 1 — одной строкой с причиной, дальше работай без внешнего агента и отметь в `final.md`. Сбой раунда 2 — пункты по шагу 5 без перекрёстной проверки.

Если автоматическая проверка отклонила запуск Claude из-за передачи незакоммиченных файлов внешнему сервису — запроси у пользователя явное разрешение передать эти изменения Claude для read-only проверки. После согласия повтори запуск с повышенными правами; без согласия не повторяй и укажи, что внешней проверки не было.
